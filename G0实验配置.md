### Step 2: SID Inference

| 配置项     | 值                       |
| ---------- | ------------------------ |
| experiment | `rqvae_inference_flat`   |
| ckpt_path  | Step 1 生成的 checkpoint |

**运行指令**:

```bash
CUDA_VISIBLE_DEVICES=1 python -m src.inference \
  experiment=rqvae_inference_flat \
  data_dir=/home/pyy/GRID/src/data/amazon_data/beauty \
  embedding_path=/home/pyy/GRID/embeddings/beauty/pickle/merged_predictions_tensor.pt \
  embedding_dim=768 \
  num_hierarchies=3 \
  codebook_width=256 \
  ckpt_path=outputs/G0_only_gpu1/G0_GRID_Baseline/01_sid_train/checkpoints/checkpoint_000_003000.ckpt \
  seed=42 \
  hydra.run.dir=outputs/G0_only_gpu1/G0_GRID_Baseline/02_sid_inference
```

> 备注：`python -m src.train` 在 `predict: true` 时也会走 `trainer.predict()`，功能上同样可用于推理；这里改用 `src.inference` 只是为了与项目标准推理入口和 `configs/inference.yaml` 保持一致，减少配置继承差异带来的隐患。
