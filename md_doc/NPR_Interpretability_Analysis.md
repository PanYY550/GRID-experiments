# 语义邻居保真度 → TIGER 下游提升：可解释性分析

> 本文档面向论文写作，构建从"表征空间语义邻居保护"到"下游推荐性能提升"的完整因果叙事。

---

## 1. 问题设定

**系统架构**：RQ-VAE（SID 生成）→ TIGER（序列推荐）

- **RQ-VAE**：将 item embedding `z_i ∈ R^768` 量化为 3 层语义 ID `SID_i = (c₁, c₂, c₃)`，每层 256 码本
- **TIGER**：自回归生成式推荐模型，输入用户历史 SID 序列，逐 token 预测下一个 item 的 SID

**核心问题**：RQ-VAE 训练中的碰撞排斥（VCF repulsion）在解决 SID 碰撞的同时，是否会破坏 embedding 空间的语义邻域结构（k-NN），从而损害 TIGER 的下游性能？

---

## 2. 因果链：从表征破坏到推荐退化

### 2.1 TIGER 为什么依赖 SID 语义一致性

TIGER 的核心能力是学习 **SID token 转移模式**：给定上下文 `(c_{t-2}, c_{t-1})`，预测 `c_t`。

关键洞察：**TIGER 的泛化能力依赖于"相似 item 有相似 SID"这一先验**。

- 如果 item A 和 item B 是语义邻居（j ∈ kNN(i)），且它们的 SID 在 Hamming 距离上接近，TIGER 学到的 A 的转移模式可以泛化到 B——即使 B 在训练中很少出现
- 反之，如果语义邻居被分配了完全不同的 SID，TIGER 需要单独学习每个 item 的转移模式，尾部 item 的推荐质量将大幅下降

这本质上是 **SID 作为协同过滤的"语义桥梁"**：SID 的层级相似性编码了 item-item 语义关系，TIGER 利用这种编码实现跨 item 的知识迁移。

### 2.2 VCF 排斥对语义结构的破坏

VCF (Vector-Quantized Contrastive Fine-tuning) 的核心操作：

> 检测 SID 碰撞的 item pair (i, j) → 在 embedding 空间推开 z_i 和 z_j

但碰撞不等于语义无关。存在两类碰撞：

| 碰撞类型 | 语义关系 | 应如何处理 |
|---------|---------|-----------|
| **伪碰撞** | j ∈ kNN(i)：语义邻居，因码本容量不足而共享 SID | 不应推开——推开破坏语义结构 |
| **真碰撞** | j ∉ kNN(i)：语义远邻，因码本分配错误而共享 SID | 应推开——纠正码本分配 |

**VCF 的盲点**：它不区分这两类碰撞，对所有碰撞对一视同仁地施加排斥力。这导致"伪碰撞"中的语义邻居被错误地推开，破坏了 embedding 空间的 k-NN 结构。

### 2.3 从 k-NN 破坏到 TIGER 退化：三步传导

```
Step 1: VCF 错误推开语义邻居
  z_i, z_j (cos_sim ≈ 0.85, j ∈ kNN(i)) → 碰撞 → VCF 排斥 → cos_sim ↓↓

Step 2: RQ-VAE 码本映射异化
  cos_sim(z_i, z_j) 下降 → 量化时 z_i, z_j 落入不同的码本区域
  → Hamming(SID_i, SID_j) 增大 → 语义邻居获得不相似的 SID

Step 3: TIGER 泛化能力下降
  语义邻居 SID 不相似 → TIGER 无法将高频 item 的转移模式迁移到低频邻居
  → 尾部 item 推荐命中率下降 → NDCG@K 整体下降
```

## 3. 实验证据

### 3.1 核心对比实验

三组实验，仅 NPR 开关不同，其他参数完全一致（3000 步，batch=256，Adam，QuaSID+TCL 底座）。

| 指标 | TCL_only (无 NPR) | NPR+TCL (有 NPR) | NPR+TCL+KPL (有 NPR+KPL) |
|------|-------------------|-------------------|--------------------------|
| **TIGER NDCG@10** | 0.0341 | **0.0355 (+4.1%)** | 0.0321 (−5.9%) |
| **TIGER NDCG@5** | 0.0283 | **0.0296 (+4.8%)** | 0.0260 (−7.9%) |
| **TIGER Recall@10** | 0.0603 | **0.0611 (+1.3%)** | 0.0584 (−3.2%) |
| **TIGER NDCG+HR@10** | 0.0944 | **0.0966 (+2.4%)** | 0.0905 (−4.1%) |

**结论**：NPR 在所有 TIGER 指标上一致优于不含 NPR 的 baseline。

### 3.2 码本利用率分析

| 指标 | TCL_only | NPR+TCL | NPR+TCL+KPL |
|------|----------|---------|-------------|
| Unique SIDs | 11645 (96.2%) | 11470 (94.8%) | 11382 (94.1%) |
| 碰撞 items | 848 (7.0%) | 1136 (9.4%) | 1261 (10.4%) |
| Max collision group | 6 | 7 | **13** |
| L0 unique tokens | 249 (97.3%) | 233 (91.0%) | 217 (84.8%) |
| L1 unique tokens | 191 (74.6%) | 176 (68.8%) | 181 (70.7%) |
| L2 unique tokens | 107 (41.8%) | 90 (35.2%) | 107 (41.8%) |

**关键发现**：NPR 的碰撞率（9.4%）反而**高于** TCL_only（7.0%），但 TIGER 性能**更好**。这直接推翻了"碰撞越少越好"的朴素假设——**碰撞的质量比碰撞的数量更重要**。

NPR 允许更多碰撞发生，是因为它不推开语义邻居（伪碰撞），这些碰撞是码本容量不足导致的"良性碰撞"——语义邻居共享 SID 不会损害 TIGER。相反，TCL_only 强行推开这些伪碰撞，减少碰撞数量的同时破坏了语义结构。

### 3.3 KPL 失败的证据

KPL 的 NDCG@10 = 0.0321，低于 TCL_only（0.0341）。同时：
- Max collision group = 13（TCL_only = 6）——KPL 的全局吸引力导致码本集中
- L0 unique tokens = 217（TCL_only = 249）——KPL 减少了码本多样性

**KPL 失败的机制解释**：KPL 对所有 k-NN 邻居施加 InfoNCE 吸引力，试图将 embedding 空间中的 K=50 个邻居全部拉近。这导致：
1. 与 VCF 排斥力产生梯度冲突（同一对 item 同时被拉近和推开）
2. 表征空间过度收缩，SID 判别力下降
3. 边缘 k-NN（rank 40-50）的噪声被放大

KPL 的失败恰恰强化了核心论点——**保护 k-NN 需要精确的"选择性保护"，而非粗暴的"全部拉近"**。

### 3.4 G0-Adam 码本崩塌的警示

| 指标 | G0-Adam |
|------|---------|
| Unique SIDs | **1**（全部 12101 items 碰撞！） |
| TIGER NDCG@10 | **0.0393** |

G0-Adam 的码本完全崩塌——所有 item 共享同一个 SID `(0, 0, 0)`。但 TIGER NDCG@10=0.0393 甚至高于 NPR+TCL！这是因为 TIGER 完全忽略了无意义的 SID，退化为一个基于 item 原始特征的序列模型。这个数字**不代表 SID 质量**——它说明 TIGER 可以在没有 SID 信号时自救，但这不是我们设计 SID-based 系统的初衷。

**教训**：TIGER NDCG 不能单独作为 SID 质量的指标。必须结合码本利用率（frac_unique）共同评判。

## 4. 理论解释：为什么保护 k-NN 结构提升 TIGER

### 4.1 SID 作为"语义哈希"

将 RQ-VAE 的量化过程视为一个**语义保持哈希函数**：

```
h: R^768 → {1,...,256}³
理想性质：cos_sim(z_i, z_j) 大 ⇒ Hamming(h(z_i), h(z_j)) 小
```

当 VCF 错误推开语义邻居后，`cos_sim(z_i, z_j)` 下降，量化边界移动，`h(z_i)` 和 `h(z_j)` 的分桶结果不同 → Hamming 距离增大 → 违反了上述理想性质。

NPR 通过保护 k-NN 结构，维护了"语义哈希"的保相似性（locality-sensitive hashing），使 SID 编码保持了从 embedding 到离散 token 的语义一致性。

### 4.2 尾部 item 的"借力"机制

TIGER 作为自回归模型，其预测能力高度依赖于 token 的**出现频率**。高频 item 的 SID 转移模式被充分学习，而低频 tail item 的转移模式几乎没有训练信号。

但 tail item 并非孤立存在——它们在 embedding 空间中往往与某些高频 item 是语义邻居（例如：热门手机 vs 冷门手机壳）。

**NPR 使这种邻居关系在 SID 层面得以保留**：
- 热门手机 SID = `(12, 45, 201)`
- 冷门手机壳 SID = `(12, 45, 198)`（前两层相同，第三层相邻）

TIGER 学到 `(12, 45)` → 手机相关 → 高概率的下一 token 是 `201` 或 `198`。这意味着 TIGER 对热门手机学到的知识，自动泛化到了冷门手机壳——这就是尾部 item 的"借力"机制。

**如果没有 NPR**：VCF 将手机和手机壳推开 → 它们的 SID 前两层不再相同 → TIGER 需要单独学习手机壳的转移模式 → 冷门 item 推荐失败。

### 4.3 全局对比：k-NN 保真度 vs 码本利用率

| 实验 | k-NN 保护 | 码本利用率 | TIGER NDCG@10 | 解读 |
|------|----------|-----------|---------------|------|
| G0-Adam | ✓（无 VCF，不存在破坏） | ✗（完全崩塌） | 0.0393 | TIGER 自救，SID 无效 |
| G0-Adagrad | ✓（无 VCF） | ✓（L1:91%, L2:95%） | 0.0322 | SID 有效但无碰撞处理 |
| TCL_only | ✗（VCF 无保护） | ✓（L0:97%） | 0.0341 | 碰撞处理但有结构损伤 |
| NPR+TCL | **✓**（VCF 有保护） | ✓（L0:91%） | **0.0355** | **最优：碰撞处理 + 结构保护** |
| NPR+TCL+KPL | ✗（过度吸引力） | △（L0:85%） | 0.0321 | 过度约束导致退化 |

**最优策略在 NPR+TCL 处**：适度的码本利用率 + k-NN 结构的精确保护。

## 5. 论文叙事框架

### 5.1 Motivation（问题）

1. RQ-VAE 用于生成 item 的语义 ID，但**码本容量有限**导致大量 item 碰撞
2. 现有碰撞处理（VCF）使用排斥损失推开碰撞 item，但**不区分语义邻居和语义远邻**
3. 错误推开语义邻居破坏了 embedding 空间的 k-NN 结构，损害下游推荐

### 5.2 Method（方法）

**Neighbor-Preserving Repulsion (NPR)**：在 VCF 排斥中引入 k-NN 感知的梯度调制——

- 若碰撞对 (i, j) 中 j 是 i 的语义邻居 → 梯度缩放至 1%（α=0.01），保护邻域
- 若碰撞对 (i, j) 中 j 不是 i 的邻居 → 全梯度排斥（α=1.0），正常纠正码本分配

```
z_i_mixed = α · z_i + (1-α) · detach(z_i)
```

### 5.3 Evidence（证据）

NPR 在所有 TIGER 指标上一致优于 baseline（NDCG@10 +4.1%，NDCG@5 +4.8%）。碰撞率虽然从 7.0% 上升到 9.4%，但**碰撞质量更高**——语义邻居更可能共享 SID，语义远邻更可能被分开。

反面对比：KPL 试图拉近所有 k-NN 邻居，反而损害了性能（NDCG@10 −5.9% vs baseline）——**证明了选择性保护优于全局保护**。

### 5.4 Insight（洞察）

> **碰撞的质量比碰撞的数量更重要。保护语义邻居的邻域结构比单纯减少碰撞数更能提升下游推荐质量。**

## 6. 开放问题与后续探索

1. **DSF（Drift Semantic Fidelity）定量测量**：per-item 的 k-NN 保留率，可作为中间指标预测 TIGER 性能
2. **RNCL（Reciprocal Neighbor Consistency Loss）**：从"防御"到"进攻"——不仅保护 k-NN 不被破坏，还主动让双向 k-NN 获得更相似的 SID
3. **Warm-start 策略**：G0-Adagrad 学码本结构 → QuaSID+NPR 做语义精修，结合两者优势
